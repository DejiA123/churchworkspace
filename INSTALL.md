# Installing Church Work Space

## What you need

One file:

**`Church Work Space Setup 2.30.0.exe`**  (about 465 MB)

That is the whole app — nothing else to download, no separate video tools to
install. If you were also sent a `.blockmap` file you can ignore or delete it;
it is a leftover of the build and is not used when installing by hand.

## Before you start

- **Windows 10 or 11, 64-bit.** This installer will not run on a Mac.
- **About 1.5 GB of free disk space** (the app unpacks to roughly 1.1 GB).
- **No administrator password needed** — it installs for your user account only.

## Windows will warn you. This is expected.

The app is not code-signed, so Windows treats it as an unknown program. You will
see one or both of these:

**1. While downloading** (Chrome or Edge) — a warning that the file "isn't
commonly downloaded" or "can't be verified". Choose **Keep**.

**2. When you run it** — a blue box:

> **Windows protected your PC**
> Microsoft Defender SmartScreen prevented an unrecognised app from starting.

Click **More info**, then **Run anyway**. The button only appears after you
click "More info".

Neither warning means anything is wrong with the file. It means Microsoft has
not seen this program before, which is true of any app that has not paid for a
code-signing certificate. If you would rather be certain, ask whoever sent it to
confirm the file size matches the one above.

## Installing

1. Double-click the `.exe`.
2. Choose where to install it (the default is fine).
3. It creates a Desktop and Start Menu shortcut called
   **Church Work Space**.

## First time you open it

- **The projector.** Plug the HDMI in *before* or *after* opening the app —
  either works. If Windows starts copying your laptop screen onto the projector
  instead of extending it, the app notices and offers a one-click fix in
  **Presentation → 🖵 Screens**.
- **Bible translations** download the first time you pick one, then work
  offline. Nothing else needs the internet.
- **The Songs Bank** starts with the song list filled in but **no lyrics** —
  those are yours to add, once per song, and it keeps them from then on. If you
  already have songs typed up, use **📚 Add my library**.

## Updating later

There is no automatic updater. To update, get the newer `.exe` and run it over
the top — your presentations, playlists, songs and settings are kept.

Everything you create lives in:

```
%APPDATA%\Church Work Space
```

Worth copying somewhere safe now and then — that folder is your songs, your
service running orders and your settings.
