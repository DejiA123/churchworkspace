Social accounts

Auto-posting accounts are linked in 📅 Social Scheduler → ＋ Connect account. The names below are only used on flyers and captions.

📘 Meta — Facebook & Instagram (for “Connect account”)

One-time setup so the app can link your Facebook & Instagram: at developers.facebook.com/apps create ONE free app (Other → Business), add the Facebook Login product and in its Settings turn ON Client OAuth login + Embedded browser OAuth login (leave redirect URIs empty, save + verify). Then paste the app's App ID + App Secret (App settings → Basic) here. Development mode is enough for Pages you admin. The full walkthrough is in Social Scheduler → ＋ Connect account.

▶️ YouTube — advanced (your own Google app)

⚡ Easiest way: skip all this and use the free Zernio API key from the TikTok section above — the same key connects YouTube too (just sign into YouTube once, no Google Cloud Console). Only fill this in if you want the app to upload straight to Google instead.

Advanced setup so the app can upload directly to your channel: at console.cloud.google.com enable the YouTube Data API v3, then create an OAuth client ID (type: Desktop app) and paste it here.

🎵 TikTok — easy connect, free & unlimited (recommended)

The 1-minute way: sign up free at zernio.com (no card), create a key under API keys in its menu, paste it here, then hit “＋ Connect account”. Public posting works right away — no TikTok developer portal, no audit wait, and no monthly post limit. Heads-up: videos upload via Zernio's servers.

⚙️ Advanced: manual Facebook token

Prefer not to use “Connect account”? Paste a Page ID + Page access token (needs pages_manage_posts) and scheduled Facebook posts publish by themselves — photos, videos, and text.
